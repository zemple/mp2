## Run

`npm install`, then `npm run dev`. `npm run build` checks TypeScript and creates `dist/`. The generated `404.html` lets GitHub Pages render direct React Router detail URLs.

## Demo checklist (under 3 minutes)

Show the deployed URL, search as you type, both sort properties and both directions, click a list item, use Previous/Next, open Gallery, select a category, and click a recipe photo. Show the detail URL and refresh it.
